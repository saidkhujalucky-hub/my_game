# ЭХО — город временных петель

Первая самостоятельная глава браузерной 3D-головоломки для Saidkhuja.

## Запустить на Windows

1. Распакуй архив и открой папку `echo-world` в VS Code — именно ту, где лежит `package.json`.
2. В терминале выполни:

```bash
npm run dev
```

3. Открой http://localhost:5173.

Нужен Node.js 20 или новее. Устанавливать зависимости через `npm install` не требуется: Three.js включён в проект. Если PowerShell блокирует `npm.ps1`, используй `npm.cmd run dev`.

Не открывай index.html двойным щелчком: браузерные модули должны загружаться через HTTP. Подходит также обычный статический веб-сервер с корнем `web/`.

## 10 уровней

Все 10 уровней лежат на одной продолжающейся карте, но у каждого уровня своя карта и свои условия: лестницы на второй и третий этаж, спуски, лабиринты, боковые крылья, лимит времени от 45 до 180 секунд и от одного до трёх рычагов. После задачи эхо стираются, а точка возрождения (R) переходит в начало следующего участка. Карты и условия — в `web/src/levels.js`.

## Что работает

- 3D-город, вода с отражениями, дождь, туман, фонари, часовая башня и затопленный трамвай.
- Первый человек: WASD или стрелки, обзор перетаскиванием мыши. V включает захват мыши, если его разрешает браузер.
- Управление касаниями: экранные стрелки, E, перемотка и жесты обзора.
- Трёхминутные циклы, точная запись положения, направления и удерживания рычагов.
- До шести прошлых версий игрока, которые повторяют его действия.
- Два независимых механизма, динамические шлюзы, трёхсимвольный резонатор.
- Карта M, журнал J, контекстная подсказка, пауза Escape.
- Автосохранение в localStorage каждые пять секунд и после важных действий.
- Процедурный звук дождя, низкий фон и звуковые сигналы. Звук включается вручную.
- FX LOW, уменьшение декоративного движения, приостановка таймера в меню и скрытой вкладке.

## Правила

Подойди к рычагу и нажми **E**, чтобы удерживать его. Нажми **R**, не отпуская рычаг: в следующем цикле твоя запись повторит путь и останется у механизма до конца цикла. Движение автоматически отпускает рычаг. Каждое эхо начинает с начала собственной записи, поэтому ему нужно время дойти до рычага.

Неудачную запись можно удалить в журнале. Если оказался за закрытым шлюзом, R всегда возвращает на первый причал. По воде ходить нельзя.

## Прохождение (спойлер)

1. Найди механизм I слева на первом причале (−5, 13). Нажми E, затем R.
2. Дождись, пока эхо возьмётся за рычаг. Пройди вперёд через мост. На второй площадке найди механизм II справа (5, −8). Нажми E, затем R.
3. Прочитай бронзовую табличку справа на первом причале (5, 16).
4. Пройди оба шлюза, когда эхо откроют их. Пульт башни находится в конце пути (0, −30).
5. Выставь символы **волна ≈ → солнце ☀ → луна ☾** и запусти башню.

## Код

- `web/src/game.js` — чистая логика: движение, границы, запись, воспроизведение, сохранение и головоломки.
- `web/src/scene.js` — Three.js: архитектура, вода, погода, механизмы, эхо, часы.
- `web/src/main.js` — управление, интерфейс, карта, журнал, настройки и автосохранение.
- `web/src/audio.js` — Web Audio без сторонних аудиофайлов.
- `web/src/style.css`, `web/index.html` — интерфейс.
- `web/assets/echo-concept.png` — художественная заставка; не скриншот реальной игровой графики.
- `web/assets/horizon.png` — дальний горный фон.
- `web/vendor/` — локальная Three.js 0.180.0 и дополнения; лицензия включена.
- `tests/game.test.mjs` — проверки движения, циклов, сохранения и полного прохождения.

## Проверки и сборка

```bash
npm test
npm run build
```

Результат — `dist/`. Это полностью статический сайт: не требуются API-ключи, аккаунты игроков, база данных или постоянно работающий Node.js-сервер на хостинге. Node.js здесь нужен только для локального запуска и копирования файлов при сборке.

Для статического хостинга: build command `npm run build`, output directory `dist`.

## Границы первой версии

Это законченная небольшая глава с двумя временными механизмами и финальным кодовым пультом, а не полноценная большая игра. В городе доступны три площадки и соединяющие их мосты; дальние здания декоративные. Игровая графика проще концепт-изображения на заставке. Дальний фон — растровая панорама, ближняя сцена — объёмная геометрия.

Логические тесты включают полное прохождение за три цикла. Визуальная проверка и замеры FPS в браузере в среде разработки не выполнялись. Для игры нужен WebGL 2. На слабом устройстве используй FX LOW; на телефоне удобнее горизонтальная ориентация. Сохранение привязано к браузеру и адресу сайта, автоматически между устройствами не переносится.
